# Rack the Rules

A pre-game rule roller for 8-ball. Seven rules are all that separate WPA 8-Ball from WEPF World Rules — this page settles which code each one follows before you break.

## How it works

- **Slide** from *All WPA* to *All WEPF*. The position sets how many of the seven rules come from WEPF; **Roll** picks which ones.
- **Rules stay coherent.** No calling means any pocket is legal for the black. Ball in hand means there is no snooker left to relieve, so the snooker rule follows it.
- **Pin** a rule to keep it through re-rolls.
- **Frame codes** (`FRAME-XXXX`) — every rule set has one. Share it and the other player gets the identical frame.
- Remembers the current frame, and prints as a card for the rail.

## Run it

One self-contained HTML file, no build step. Open `index.html` in a browser, or serve it with GitHub Pages.
